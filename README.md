# SangamSD website

A vibrant, accessible React/Vite website for SangamSD.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Updating content

Evergreen site content, event placeholders, and the single published board roster live near the top of `src/App.jsx`. Replace the `events` and `board` arrays once the 2026–2027 calendar and incoming board are confirmed. The current portraits are stored in `public/board`, and the design intentionally does not include a previous-board archive.

The official SangamSD logo lives in `public/brand`. The site palette uses the logo’s saffron-orange, royal blue, periwinkle, and navy over a warm ivory canvas. SangamSD photography and event footage are stored locally in `public/media`, so the visuals do not depend on the old website remaining available.
